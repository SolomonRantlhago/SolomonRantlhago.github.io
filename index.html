About Me

I am a software development professional from Ga-Rankuwa, Pretoria, with a BSc in Information Technology from the University of the Free State, majoring in Computer Science and Business Management, and a National Certificate in IT (System Development), NQF Level 5, completed through the Umuzi learnership programme.

I am passionate about problem-solving, continuous learning, and building reliable, user-focused software solutions. My goal is to continue growing as a software developer, deepen my technical expertise, and contribute to projects that address real-world problems.

Projects

Library Management System

A browser-based Library Management System that supports physical and digital book management, member registration, borrowing and returning books, overdue tracking, and fine calculation.

The system uses object-oriented programming, including classes, inheritance, private fields, getters and setters. Its architecture separates business logic from UI functionality, with data persistence through localStorage and a Node.js/Express server.

Technologies: JavaScript (ES6+), HTML, CSS, Node.js, Express, Jest
GitHub Repository Live Demo

React Fitness Tracker & Workout Planner

A responsive, single-page React application that allows users to browse exercises, create weekly workout plans, log completed workouts, and track their fitness progress.

Users can explore 21 exercises using search and filtering, view detailed exercise instructions and demonstration videos, and create workout routines for Monday through Sunday. The application also provides workout history, progress statistics, and visual progress charts.

The application uses React Context API for shared state management and localStorage to preserve workout plans and history across page refreshes. It also includes unit and integration tests using Vitest and React Testing Library.

Technologies: React 19, React Router v7, JavaScript, Context API, localStorage, CSS Modules, Vitest, React Testing Library
GitHub Repository Live Demo

Book Collection Application

A web application built using ASP.NET Core 3.1 MVC and C# that allows users to keep track of books they have read and books they would like to read.

The application provides a simple way to organise and manage a personal book collection, making it easier for users to keep track of their reading progress.

Technologies: ASP.NET Core 3.1 MVC, C#, HTML, CSS, Bootstrap 4
